🚀 Quickstart & How to Run

Set up your Android phone as a dedicated SMS gateway in 4 simple steps:

Step 1: Download & Install APK

Download the latest release APK from GitHub Releases. Install the APK on your device (temporarily allow installation from unknown sources).

Step 2: Grant Permissions

When launching OpenSMS, grant SMS, WakeLock, and Notification permissions.

⚠️ Android 13+ "Restricted Settings" Bypass
On Android 13, 14, and 15+, SMS permissions are restricted on sideloaded apps by default. To unlock:
  1. Go to Settings → Apps → OpenSMS.
  2. Tap the three dots (⋮) in the top-right corner.
  3. Tap Allow restricted settings.
  4. Return to Permissions and enable SMS.

Step 3: Start Server & Generate API Key

Tap Start Server on the main screen. If prompted, tap Generate to create your cryptographically secure Bearer token (osms_...) and copy it to your clipboard.

Step 4: Dispatch Your First SMS

Terminal (cURL) 
curl -i -X POST 'http://<DEVICE_IP>:9292/sms/' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer osms_your_secret_key' \
  -d '{
    "number": "+1234567890",
    "text": "Hello world from OpenSMS Gateway!"
  }'

🌐 Cross-Network Connectivity (Tailscale Mesh)

When your phone is on cellular mobile data (CGNAT) and your cloud server or laptop is on a different network, you do not need open ports or router port forwarding. Use Tailscale WireGuard Mesh:

  1. Install Tailscale on your Android phone and on your server/laptop.
  2. Log in with the same account on both devices.
  3. Open the Mesh tab inside OpenSMS. OpenSMS automatically detects the 100.x.y.z Tailscale CGNAT IP address and shows the green Connected pill.
  4. Now simply target http://100.x.y.z:9292/sms/ from anywhere in the world!

🔐 Authentication & Rate Limiting

All API endpoints except /health/ and /llms.txt require Bearer token authentication:

HTTP Header
Authorization: Bearer osms_your_secret_api_key

Brute-Force Rate Limiting: A maximum of 10 failed authentication attempts per client address is permitted within a 60-second sliding window (the socket address is used; X-Forwarded-For is ignored). Each API key may also send at most 300 messages per minute. Exceeding this returns HTTP 429 Too Many Requests.

POST /sms/

Send Single SMS

Dispatches an SMS to a single recipient with automatic phone sanitization and optional dual-SIM slot selection.

FieldTypeRequiredDescription
numberstringYesDestination phone number in international E.164 format.
textstringYesMessage text body. Plain text (GSM-7) or Unicode (UCS-2).
sim_slotintegerNoCarrier slot index (0 for SIM 1, 1 for SIM 2).
Example Response (200 OK)
{
  "id": "3f2b8c1a-9d4e-4a6b-8c2d-7e1f0a5b9c42",
  "number": "+1234567890",
  "stat": true,
  "sim_slot": 0,
  "segments": 1,
  "encoding": "GSM-7"
}
POST /sms/batch/

Send Batch SMS (Up to 100 Recipients)

Dispatches multiple messages sequentially with automated 100ms hardware pacing delay to prevent cellular baseband radio saturation.

Request Body
{
  "sim_slot": 0,
  "messages": [
    { "number": "+1234567890", "text": "System alert: CPU load normal." },
    { "number": "+1987654321", "text": "System alert: CPU load normal." }
  ]
}
GET /sms/{id}

Get SMS Delivery Status by ID

Retrieves persistent message lifecycle status (queued, submitted, sent, delivered, failed, unknown), timestamps, and cellular carrier error details from SQLite.

Response (200 OK)
{
  "id": "3f2b8c1a-9d4e-4a6b-8c2d-7e1f0a5b9c42",
  "recipient": "+1234567890",
  "text": "Hello from OpenSMS!",
  "encoding": "GSM-7",
  "segments": 1,
  "sim_slot": 0,
  "status": "sent",
  "created_at": 1729432800.12,
  "delivered_at": 1729432801.45,
  "carrier_error": null
}
GET /sms/history/

List Historical Messages

Paginated history with query parameters: limit (default 50), offset, status (all, sent, failed, queued), and search.

GET /system/stats/

System Telemetry & Live Metrics

Returns live gateway metrics including messages sent today, success rate %, and active queue depth.

GET /system/sims/

List Active SIM Slots

Detects and lists active cellular SIM slots and carrier network names via Android SubscriptionManager.

GET /system/update/

Check for GitHub Updates

Queries GitHub Releases to check if a newer OpenSMS APK is available.

GET /health/

Health Check

Unauthenticated liveness probe returning {"status": "ok", "service": "OpenSMS", "version": "0.4.0"}.

🐍 Python SDK Integration

Python (requests)
import requests

def send_sms(number: str, message: str, sim_slot: int = 0):
    url = "http://100.85.12.34:9292/sms/"
    headers = {
        "Authorization": "Bearer osms_your_secret_key",
        "Content-Type": "application/json"
    }
    payload = {
        "number": number,
        "text": message,
        "sim_slot": sim_slot
    }
    response = requests.post(url, json=payload, headers=headers)
    return response.json()

print(send_sms("+1234567890", "Alert from Python server!"))

🟦 TypeScript & Node.js Integration

TypeScript (fetch)
async function sendSms(number: string, text: string) {
  const response = await fetch("http://100.85.12.34:9292/sms/", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "Authorization": "Bearer osms_your_secret_key"
    },
    body: JSON.stringify({ number, text, sim_slot: 0 })
  });

  if (!response.ok) {
    throw new Error(`Failed to send SMS: ${await response.text()}`);
  }
  return response.json();
}

🔷 Go Integration

Go
package main

import (
	"bytes"
	"encoding/json"
	"fmt"
	"net/http"
)

func main() {
	payload, _ := json.Marshal(map[string]interface{}{
		"number":   "+1234567890",
		"text":     "Alert from Go service",
		"sim_slot": 0,
	})

	req, _ := http.NewRequest("POST", "http://100.85.12.34:9292/sms/", bytes.NewBuffer(payload))
	req.Header.Set("Authorization", "Bearer osms_your_secret_key")
	req.Header.Set("Content-Type", "application/json")

	client := &http.Client{}
	resp, _ := client.Do(req)
	defer resp.Body.Close()
	fmt.Println("Status:", resp.Status)
}

📱 Dual-SIM Telephony Architecture

OpenSMS uses Android's native SubscriptionManager to discover all active carrier SIM cards. You can toggle between Auto, SIM 1, and SIM 2 in the in-app Settings, or dynamically pass "sim_slot": 0 or "sim_slot": 1 in any API request.

💾 SQLite WAL Persistence

Starting in v0.4.0, all messages, delivery timestamps, API keys, and metrics are persisted in a local SQLite database operating in Write-Ahead Logging (WAL) mode. This ensures maximum concurrency and zero locking between background FastAPI server threads and the Kivy UI.

🛠️ Troubleshooting & FAQ

Device stops receiving requests

Ensure battery optimization for OpenSMS is set to Unrestricted. On MIUI/OneUI, enable Autostart.

SMS Fails with Carrier Error

Ensure the SIM card has an active text messaging plan and sufficient credit. Verify cellular signal bars on the status bar.

Messages > 160 Characters

OpenSMS automatically divides long messages into multipart segments. Emojis trigger UCS-2 Unicode mode (70 chars/segment).
